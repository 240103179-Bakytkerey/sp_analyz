# JUZ40 · SMART PRO кері байланыс платформасы

SMART PRO-1/2/3 мұғалімдеріне **ЛС** (LIVE сабақ), **СТ** (сабақ тапсыру) және **БТ** (байқау тесті) бойынша кері байланыс беретін сайт.
Көрнекі тілі мен қаңқасы — [keribailanys.vercel.app](https://keribailanys.vercel.app) (`anonens/lskb`) сайтының кеңейтілген нұсқасы:
қою көк кіріспе → мұғалімдер тізімі → әр мұғалімге ірі фотосы мен ірі сандары бар жеке бөлім → қорытынды және «Таныстым».

## Не істейді

| Бөлім | Мүмкіндік |
| --- | --- |
| Көру беті `/` | ЛС / СТ / БТ, ағым (Барлығы, SP-1/2/3), пән (іздеуі бар топталған панель), кезең, комбинация (Барлығы / БХ / ФХ / …). Тікелей сілтеме: `/?t=ls&s=sp1&subj=chemistry&p=5-2#r-<есеп>` — бет жаңарғанда сүзгілер қалпына келеді |
| Мұғалім бөлімі | ЛС: ұнату %, қатысым (Σ/Σ), Ұнады/Орташа/Ұнамады, түсіну санаттары, комбинациялар, ортақ сабақ белгісі, ментор қорытындысы мен ұсынысы, толық есеп (сабақтар, оқушы аттары тек осында). СТ: ортақ балл/макс, дереккөзі (платформа/қолмен/салмақталған), қайта тапсыру, комбинациялар, шектеусіз қиын тапсырмалар (формула, сурет, нұсқа, тақырып, түсіндірме). БТ: жалпы нәтиже, жалпы ТОП-3, пәндік нәтижелер мұғаліммен байланысады, «ОС» сияқты қосымша көрсеткіш |
| Динамика | Тікелей алдыңғы оқу аптасымен (ағымның күнтізбесі бойынша, ай шекарасында да), БТ — алдыңғы салыстыруға жарамды БТ-мен. Балл — «балл», пайыздар — «п.т.», қайта тапсыру төмендесе — прогресс. Белгі + мәтін + салыстыру кезеңі. «Алдыңғы апта дерегі жоқ» күйі, максимал балл өзгерсе — үлес салыстырылады, мұғалім/комбинация/когорта өзгерсе — ескерту |
| «Таныстым» | Серверде: кім, қай есеп, қай жарияланған нұсқа, қашан. Есеп мазмұны өзгеріп қайта жарияланса — «есеп жаңартылды» |
| Әкімші бөлімі `/admin` | Есептер (ЛС/СТ/БТ формалары, жоба/жариялау, алдын ала қарау, нұсқалар, кім таныстық), Импорт (SapaLine, JSON резерві, платформа, Telegram мәтінінен жоба), Анықтамалық, Пайдаланушылар, Импорт баптауы, Тарих |

## Есептеу ережелері (`lib/calc.js` — сервер мен бет бірдей қолданады)

- Ұнату = Ұнады ÷ (Ұнады + Орташа + Ұнамады) × 100; апталық мән — сабақтардың жауап сандарының қосындысынан.
- Қатысым = Σ қатысқан ÷ Σ жалпы (сабақтар бойынша қатысым, бірегей оқушылар емес). Тек пайыз бар сабақтар бөлек белгіленеді. 100%-дан асса — қиылмайды, белгіленеді.
- Түсіну деңгейі — тек санаттардың жауап саны; орташа түсіну пайызы ойдан есептелмейді.
- Ортақ сабақ (бір ЛС-қа бірнеше комбинация, бөлініс жоқ) «Барлығы» көрінісінде бір рет саналады, комбинацияға көшірілмейді. Ментор бөлініс енгізсе — комбинацияға шығады.
- СТ жалпы балл: платформаның мәні → ментордың жалпы мәні → Σ(балл × тапсырған) ÷ Σ тапсырған. Салмақ жоқ болса — жалпы көрсетілмейді.
- Қайта тапсыру: сан/бөлгіш немесе дереккөз пайызы; бөлгіш ойдан табылмайды, баллға шек қойылмайды.
- `null` — дерек жоқ, `0` — нөл. Дөңгелектеу тек көрсетерде.

## Деректер

Postgres (`lib/migrations/001_init.sql`): `users`, `subjects`, `streams`, `combinations`, `teachers`, `assignments` (қолданылу кезеңімен),
`periods` (әр ағымның күнтізбесі, `seq` — нақты рет), `reports` (түрі, ағым, пән, мұғалім — тарихи түрде сақталады, кезең, scope, күй,
`version`, жоба `data` және жарияланған көшірме `published`), `report_revisions`, `acknowledgements`, `import_mappings`, `import_runs`, `audit`, `photos`.
СТ-да платформа сандары `data.imported` ішінде, ментордың мәтіні бөлек; ЛС сабақтарында `source`/`sourceId`/`importedAt`.

Бастапқы анықтамалық (`seed/catalog.json`): **16 пән, 3 ағым, 26 мұғалім, 48 тағайындау**, комбинациялар тек БХ және ФХ.
Геометрия математикадан бөлек пән (сол ағымның математика мұғалімі береді). TOEFL — Амирбекова Ажар. Фото тек аты-жөні lskb-мен дәл
сәйкес екі мұғалімге қойылды (Құлахмет Нұрдәулет, Бекет Ерсұлтан); қалғанына инициалдар. lskb-дағы «Олжас Нұрдәулет» фотосы
«Нұрдаулет Олжас»-қа сенімді сәйкестендірілмегендіктен қойылмады — әкімші тексеріп жүктей алады.

Қатар өңдеу: әр сақтау `version` тексереді; басқа адам ертерек сақтаса — 409, өзгеріс үнсіз жоғалмайды (форма «менің нұсқам / жаңа нұсқа» таңдауын ұсынады).
Әр сақтау нұсқа ретінде қалады; әкімші кез келген нұсқаны қалпына келтіре алады.

## Рөлдер

`admin`, `mentor`, `viewer` — әр адамға жеке аккаунт. Рұқсат әр API әрекетінде серверде тексеріледі. Менторды ағым/пән/түр бойынша шектеуге болады.
Көрушіні мұғалім профиліне байланыстырса, «Таныстым» оның өз есептеріне қойылады. Әкімші бекітетін қосымша кезең жоқ (кейін `publishReport` ішіне қосуға болады).

## Іске қосу (компьютерде)

Node.js 22. Дерекқор берілмесе, `./.data/pg` ішіндегі PGlite (нақты Postgres, WASM) қолданылады.

```bash
npm install
```

```bash
cp .env.example .env.local
```

`.env.local` ішінде `BOOTSTRAP_ADMIN_USERNAME` және `BOOTSTRAP_ADMIN_PASSWORD` толтырыңыз, сосын:

```bash
npm run dev
```

http://localhost:3000 (әкімші бөлімі: `/admin`). Басқа аккаунттар әкімші бөлімінде немесе:

```bash
npm run user -- --username aigerim --role mentor --name "Айгерім"
```

Демо деректер (бәрі «Демо деректер» белгісімен; тек промпттағы нақты үлгілер) және оларды өшіру:

```bash
npm run demo
```

```bash
npm run demo -- --remove
```

Тексерістер (есептеу, рөлдер, қатар сақтау, «Таныстым», қайта импорт, динамика, БТ, SapaLine адаптері):

```bash
npm test
```

## Vercel-ге шығару

1. Vercel → **Add New → Project** → осы репозиторий. Framework: **Other** (баптау `vercel.json` ішінде).
2. **Storage → Create → Neon (Postgres)** → жобаға қосыңыз: `DATABASE_URL` өзі қосылады. Кестелер мен 16 пәндік анықтамалық алғашқы сұраныста жасалады.
3. **Settings → Environment Variables**: `SESSION_SECRET` (кемі 16 таңба), бірінші кіру үшін `BOOTSTRAP_ADMIN_USERNAME`/`BOOTSTRAP_ADMIN_PASSWORD`
   (кейін өшіріңіз), қажет болса `SAPALINE_*`, `JUZ40_*`, `PUBLIC_VIEW`.
4. **Deploy** → `/admin` → кіріңіз → «Пайдаланушылар» бөлімінде менторлар мен көрушілерді қосыңыз → «Импорт баптауы».
